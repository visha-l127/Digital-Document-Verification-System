# Digital-Document-Verfication-System

Overview

The Digital Document Verification System is a Java-based application designed to manage and verify digital documents efficiently. The system allows users to add, update, view, and verify document records while maintaining verification logs for tracking verification activities and document status.

Features

- Add and manage document records
- View and update document information
- Verify documents and track verification status
- Maintain verification logs for auditing purposes
- Input validation using custom exception handling
- Persistent data storage using Oracle Database
- Database connectivity through JDBC

Technologies Used

- Java
- Object-Oriented Programming (OOP)
- JDBC
- Oracle Database
- SQL
- Eclipse IDE
- Exception Handling

Project Structure

- Model Classes – Represent document and verification entities
- Service Classes – Handle business logic and verification operations
- Exception Classes – Manage custom validation and error handling
- Database Layer – Store and retrieve document information using JDBC

Key Concepts Implemented

- Encapsulation
- Inheritance
- Polymorphism
- Exception Handling
- Database Integration
- Modular Programming

Purpose

This project demonstrates how Java applications can be integrated with a relational database to build a reliable document verification system. It focuses on efficient document management, verification tracking, and maintaining data integrity through proper validation and error handling.
